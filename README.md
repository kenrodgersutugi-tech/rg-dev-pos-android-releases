# RG Dev POS for Android: downloads

Releases only; the source code is private.

- **Download:** the newest `RG-Dev-POS.apk` from [Releases](../../releases/latest), or the [download page](https://kenrodgersutugi-tech.github.io/rg-dev-pos-releases/android.html) with install help.
- **Updates:** installed phones read the signed `update.json` attached to the latest release. They download newer versions by themselves and ask before installing.
- Every APK is signed with the RG Devs release key. Android refuses an update signed with anything else.
